🌐 TOP STORIES

OpenAI Validates 948 Linux Kernel Privilege-Escalation Bugs With GPT-6 Cyber

OpenAI reports that an autonomous pipeline powered by GPT-6 Cyber identified 2,308 candidate Linux kernel findings, reproduced 1,724 vulnerabilities and produced 948 distinct local privilege-escalation exploits, allowing unprivileged local users to gain root access. The pipeline generated candidate patches, which human researchers reviewed before disclosure; OpenAI reports a $1.21 million API-credit cost for the run.

Baidu Releases Apache 2.0 Weights for ERNIE 5.5 Flash Preview

Baidu released ERNIE 5.5 Flash Preview weights under Apache 2.0. The mixture-of-experts model has 280B total parameters, 14B active per token and a 1M-token context. Baidu says post-training is still underway, so the checkpoint is not the final release, and its benchmark comparisons remain company-reported.

Z.ai Announces GLM-5.4 With a Loop-Transformer Coding Architecture

Z.ai announced GLM-5.4, a model built by looping layers from the GLM-5 base model for deeper reasoning. The company says it extends coding into video, games, 3D shaders and CAD and adds vision capabilities. API access will open only after safety evaluation, and Z.ai said model weights will be released responsibly.

Ant Ling Releases Open-Weight Ling-3.2-Air Multimodal Model

Ant Ling released Ling-3.2-air, an open-weight native multimodal mixture-of-experts model with 124B total parameters and 5.5B active per token. Its model card says the release improves workflow automation and professional-document reasoning, with AutomationBench-AA rising from 15.7% to 61%. The benchmark result is reported by the developer.

Anthropic Opens Zero-Data-Retention Enterprise Safeguards in Beta

Anthropic opened Enterprise Frontier Safeguards in public beta for eligible business customers. The service is designed to detect sophisticated misuse while remaining compatible with zero data retention, with inputs and outputs sent to customer-controlled storage. Anthropic said it developed the system with more than 100 customers, including a quarter of the Fortune 100.
