🌐 TOP STORIES

Z.ai Releases GLM-5.4, Its First Loop Transformer

Z.ai released GLM-5.4, which it calls its first Loop Transformer: the model reuses 28 layers of the GLM-5 base across two iterations to reason more deeply without adding parameters. Z.ai's documentation lists a 1M-token context, 128K maximum output and video, image, text and file input, and positions the model for generalized coding including video, games and CAD. It is available to GLM Coding Plan users, while API access awaits a security assessment.

Nvidia Board Reinstates Jensen Huang as CEO

Nvidia's board voted unanimously to reinstate Jensen Huang as president, CEO and director effective immediately, saying it was satisfied with his candor and ability to lead. The board said input from senior levels of the US government left it confident his return poses no national security risk, and an independent committee's investigation into reports of a foreign intelligence effort targeting him will continue. CNBC reported the stock rose 31%.

Baidu Opens Weights for ERNIE 5.5 Flash Preview Under Apache 2.0

Baidu said on X that weights for ERNIE 5.5 Flash Preview are now available under Apache 2.0, with Day-0 SGLang support. The mixture-of-experts model has 280B total and 14B active parameters and a 1M-token context, and Baidu says post-training is ongoing. Baidu first offered the model through its Qianfan API, and its release page highlights coding, 3D modeling and game development tasks completed inside an agent harness.

Microsoft AI Details Rocket RL Framework Used to Post-Train MAI Base 2

Microsoft AI described Rocket, its in-house reinforcement learning framework, and said its roughly three-trillion-parameter MAI Base 2 is now being post-trained with it without distillation from third-party models. The post covers runs of thousands of training steps over weeks to months on thousands of GPUs, addressing rollout staleness, sampler-learner numerical mismatch and hardware failures. Benchmark results are not yet published; Microsoft AI says details will follow after release.

OpenAI and Cisco Launch Shirudo, an Open-Source Linux Runtime for AI-Assisted Defense

OpenAI and Cisco launched Shirudo, an open-source runtime that lets security teams deploy signed eBPF shields against vulnerable Linux code paths while services keep running, with a TPM-backed record of what was loaded. In a controlled test, a Codex-generated shield blocked a Java4Shell exploit attempt against a live Elasticsearch service without a restart. Operators approve each shield before it is deployed.
