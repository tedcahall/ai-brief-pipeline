🌐 TOP STORIES

Nvidia Board Reinstates Jensen Huang as CEO

New developments: Nvidia said its board voted unanimously to reinstate Jensen Huang as president, CEO and board member, effective immediately. The board said input from senior levels of the US government left it confident the move poses no national security risk. An independent committee investigation will continue, and Nvidia is adding a National Security and Export Control Committee and searching for a Chief Compliance Officer.

Z.ai Introduces GLM-5.4, Its First Loop Transformer Flagship

Z.ai released GLM-5.4, its first flagship built on a Loop Transformer, which reuses 28 layers of the GLM-5 base model across two iterations at the 750B scale. Z.ai says it reaches intelligence comparable to 2T to 3T parameter models and extends coding to video, games, 3D modeling and CAD. It is available to GLM Coding Plan users, with API access pending a security assessment.

OpenAI and Cisco Open-Source Shirudo to Shield Linux Systems During Patching

OpenAI and Cisco launched Shirudo, an open-source Linux runtime that uses eBPF so agents can develop and test temporary shields that block exploit behavior on running systems, with operators approving deployment. In a controlled test, a Codex-generated shield blocked a Java4Shell exploit attempt against Elasticsearch without a restart. Separately, OpenAI said a research pipeline produced 948 Linux kernel local privilege escalation exploits and candidate patches.

Anthropic Launches Claude Ship to Review, Fix and Approve Code Changes

Anthropic launched Claude Ship, a suite of agents for automating code reviews, fixes and approvals of routine changes, TechCrunch reported. It combines the generally available Code Review with two beta agents: PR Steward, which addresses failing CI checks, merge conflicts and review feedback, and Claude Approvals, which applies a policy file the team writes. It is rolling out to Claude Team and Enterprise plans for GitHub repositories.

Amazon Confirms Deal for Decart's AI Optimization Technology and Team

New developments: Amazon confirmed it signed an agreement to purchase the technology behind the Decart Optimization Stack and bring Decart's three co-founders and their team to Amazon, following earlier reports of talks. Amazon did not disclose terms; Bloomberg reported a price of about $7.5 billion, according to GeekWire. Amazon says the technology will help optimize inference and its custom silicon. Closing requires regulatory clearance.
