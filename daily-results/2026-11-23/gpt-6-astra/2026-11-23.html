🌐 TOP STORIES

Ant Releases Open-Weight LingSante Medical Models

Ant Ling announced LingSante-3.1-flash, a 560-billion-parameter medical model with 25 billion active parameters, alongside the multimodal LingSante-3.1-air-VL. The released model cards describe medical reasoning, evidence retrieval and tool-driven workflows. Flash supports a one-million-token context window. These are research models, not medical devices; vendor benchmark results do not establish clinical effectiveness.

Microsoft Backs Shared Pretraining Evaluations

Microsoft AI chief Mustafa Suleyman endorsed OpenAI’s transparency initiative and committed to sharing pretraining progress on a common held-out evaluation set. He reported MAI-2 Base log-perplexity of 0.819 using OpenAI’s evaluation set and tokenizer. He also cautioned that comparisons across different tokenizers may require bits-per-byte and additional datasets. This is a company-reported evaluation, not an independent capability ranking.

vLLM Tests NVMe Instead of a DRAM Cache Tier

vLLM reports that a 1.8 TB NVMe cache pool matched an equally sized DRAM pool within 1% of throughput while serving Kimi-K3 on 16 AMD MI355X GPUs. The tests replayed agent workloads at three concurrency levels. Small DRAM buffers remained in use, and SSD write endurance is a limitation; the result is workload-specific, not a universal storage-speed equivalence.

Apple Recruits for a Computer-Use AI Agent

Dataconomy reports that Apple is recruiting a senior engineering manager for an autonomous assistant able to browse, use applications, run commands and write or debug code. The report quotes a job listing describing tool selection across computer workflows. Apple has not announced a release date, so this is evidence of development plans rather than a shipping product.

Governors Propose Shared Federal-State AI Rules

The National Governors Association released AI governance principles calling for complementary federal and state roles, evidence-based safeguards and protection for workers and consumers. The recommendations seek fewer conflicting requirements while preserving state authority over deployment within states’ responsibilities. They also urge rules that do not favor large incumbents. This is a policy proposal, not newly enacted legislation.
