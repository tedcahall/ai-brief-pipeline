🌐 TOP STORIES

OpenAI Proposes Perplexity as a Shared Yardstick for AI Safety Limits

OpenAI chief scientist Jakub Pachocki published an essay, "Perplexity and Intelligence," proposing perplexity (cross-entropy loss) as a common metric for labs to compare pretraining progress and agree on shared safety limits. OpenAI disclosed its own internal log-perplexity curve, and Microsoft's Mustafa Suleyman committed to reporting MAI-2 Base on OpenAI's held-out evaluation set.

Amazon Details AI Agents Exploiting a Zero-Day in Medical-Imaging Software

Amazon Threat Intelligence detailed a September intrusion in which a China-linked threat actor used autonomous AI agents built on a tool called Cairn to find and exploit a zero-day in the open-source MONAI Label medical-imaging framework. The agents went from mapping the application's API to writing files on the server in about 11 minutes, then planted a reverse shell to gain root access.

DeepSeek Closes About $15 Billion Funding Round Ahead of Shanghai IPO

Chinese AI developer DeepSeek completed a second external funding round of about 100 billion yuan (about $15 billion), according to Caixin, as it prepares for an initial public offering on Shanghai's STAR Market. The round drew 31 new investors, many tied to Chinese state capital, and valued the company at roughly 615.5 billion yuan.

Moonshot AI Publishes Open Weights for 2.8-Trillion-Parameter Kimi K3.1 Pro

Moonshot AI released open weights for Kimi K3.1 Pro, a natively multimodal 2.8-trillion-parameter mixture-of-experts model with 104 billion active parameters per token and a 1-million-token context window. SGLang reported the model delivers 6.5x better performance per dollar on Nvidia Rubin NVL72 than on GB300 NVL72 in an MLPerf-style submission.

Apple Is Building an Autonomous AI Agent for Device Control and Coding

Apple is developing its own autonomous AI agent that can browse the web, use apps, run commands and write or debug code on a user's behalf, according to Bloomberg. The effort aims to counter similar offerings from OpenAI, Anthropic, Meta and others, with a proactive Siri agent reportedly targeted for as early as 2027.
