🌐 TOP STORIES

Meituan launches LongCat-2.5 for multimodal agent work

Meituan released LongCat-2.5, a multimodal model with 1.6 trillion total parameters and about 48 billion active per token, TechNode reports. The company says long-sequence training and reinforcement learning improve extended coding tasks, with real agent failures converted into reproducible training problems. Chat and API access are available; GitHub and Hugging Face releases were still described as forthcoming.

GDPx tests frontier agents across 11 demanding domains

SemiAnalysis introduced GDPx, an agent benchmark spanning 11 domains including chip design, biology, finance and software engineering. Its reported best overall score is 12%, with results varying sharply by domain and safety refusals affecting some rankings. Tasks run in simulated work environments, generally with an eight-hour limit. These are the evaluator’s results, not a universal measure of workplace productivity.

MiniMax details local deployment options for M3.1 Flash

MiniMax highlighted community quantization work for its 428-billion-parameter M3.1 Flash model, including Unsloth’s 143.9 GB two-bit GGUF weights, Apple Silicon workflows and AMD Instinct support. The company describes calibration, low-bit kernels and expert placement across GPU and system memory as necessary to make the savings useful. The announcement expands deployment guidance; it is not a newly released base model or independent performance test.

Cisco Talos finds AI-assisted victim ranking in VOLTA malware

Cisco Talos analyzed a Windows infostealer that adds an optional AI stage after collecting credentials and other personal data. VOLTA sends an evidence bundle to models to rank stolen assets and assess victims, with a Claude-to-Kimi-to-Gemini fallback chain designed to handle refusals. Talos documents malware behavior, not an autonomous model escape; the theft can also proceed without the AI stage.

Frank Calegari urges mathematics to rethink AI-era incentives

In a guest essay on Terence Tao’s blog, mathematician Frank Calegari argues that AI-assisted proofs should shift attention toward choosing worthwhile problems and explaining mathematical understanding. He proposes changes to hiring, journal standards and graduate training while criticizing errors and attribution in OpenAI’s papers. This is a researcher’s proposal for adapting mathematical institutions, not an announcement that the cited proofs have been independently accepted.
