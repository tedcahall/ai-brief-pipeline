📊 AI INDUSTRY PULSE

Frontier-agent evaluation and orchestration moved forward as SemiAnalysis released the 206-task GDPx benchmark and DeepSeek described its router-and-worker Super Agent architecture. GDPx leaves substantial headroom, with Claude Opus 5.5 leading its debut leaderboard at 12%, while DeepSeek is targeting the human attention bottleneck in parallel agent work.

NVIDIA’s latest AgentX submission reported inference above 1,000 tokens per second per user for 700B+ parameter models, alongside large claimed gains in Rubin performance per cost. 🌐 TOP STORIES

SemiAnalysis launches GDPx, and the best model scores just 12%

SemiAnalysis introduced GDPx, a 206-task agentic benchmark spanning 11 professional domains built with specialized partners. Claude Opus 5.5 leads the initial 13-model leaderboard at 12%, followed by Gemini 4 Carbon at 10.9% and GPT-6 Astra at 9.6%. The eight-hour tasks emphasize realistic environments, while safety classifiers affect some domain scores.

DeepSeek unveils Super Agent for coordinating parallel AI work

DeepSeek disclosed Super Agent, an architecture intended to coordinate multiple assignments without requiring users to manage separate conversations. A router gathers events from sources including chat and email and distributes work to parallel workers, while people set goals and review results. DeepSeek says the prototype applies established computing design concepts rather than introducing a new theory.

Cisco Talos finds infostealer using AI to rank victims by asset value

Cisco Talos analyzed VOLTA-AUTODOXER, a self-deleting Windows infostealer that sends stolen identity and asset data through OpenRouter for victim prioritization. It defaults to Claude Opus 4.6, then tries Kimi K2 and Gemini 2.5 Flash after refusals. Talos says the AI layer displaces criminal analysis work and is optional, not a demonstrated autonomous containment failure.

NVIDIA AgentX submission passes 1,000 tokens per second on 700B+ models

A new NVIDIA AgentX submission uses agent-swarm-written software to exceed 1,000 tokens per second per user on models above 700 billion parameters, according to SemiAnalysis. On Rubin NVL72, it reports 20.9 times GB300 NVL72 performance per total cost of ownership at 325 tokens per second. These are benchmark submission results, not independent broad workload measurements.

Andrej Karpathy builds HackerTube with Claude in about two hours

Andrej Karpathy used Claude Code and Opus 5.5 to filter 43 million Hacker News comments into 6,454 repeatedly recommended YouTube videos. The resulting HackerTube site replaces uploaded thumbnails with representative frames and keeps login-free state locally. Karpathy says the weekend project took about two hours, with Claude handling deployment and optimization after limited manual setup.
