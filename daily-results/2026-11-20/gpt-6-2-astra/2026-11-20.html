📊 AI INDUSTRY PULSE

Tencent released the weights for Hy4, its million-token multimodal model, along with the system card describing how it was tested. Apple released Depth Pro 2 for a narrower task: estimating real-world distances from ordinary camera footage without the depth map flickering between frames.

For developers choosing where to run models, AMD and Unsloth added an option on compatible PCs: run inference on the neural processing unit rather than the GPU.

🌐 TOP STORIES

Tencent releases open weights for Hy4

Tencent released the weights for its multimodal Hy4 model under the Tencent Hy License. The model activates 49 billion of its 770 billion parameters and supports a million-token context window. Developers can now serve it with vLLM or SGLang and consult a system card that documents Tencent’s safety evaluations.

Apple’s Depth Pro 2 estimates distance from ordinary video

Depth Pro 2 estimates the distance in meters to each pixel in a photo, video or live camera feed. Apple offers four sizes, from 24 million to 872 million parameters, so researchers can trade speed for sharper boundaries and less jitter between frames. The weights are licensed for noncommercial research, not product deployment.

ElevenLabs narrows the transcription gap on an independent test

Artificial Analysis measured a 1.95% word error rate for ElevenLabs’ Scribe v3 on its non-streaming transcription index, down from 2.18% for v2. Alibaba’s Fun-Realtime-ASR-preview still leads at 1.73%. The comparison measures errors in completed transcripts, not how quickly a listener sees words during a live conversation.

AMD and Unsloth bring on-device inference to the NPU

AMD says Unsloth Desktop can now run local inference on its XDNA 2 neural processing units. More than 100 compatible agent applications and workflows can use that path, according to AMD. The change gives users of supported PCs a way to run models locally without assigning the same work to a GPU.

LangSmith puts identity and access checks on agent tool calls

LangChain opened a public beta of Tool Gateway for the LangSmith Agent Platform. It manages credentials, identity and access when an agent calls a tool, and records the action. For teams moving from chat to scheduled work, that lets them specify whose permissions an agent uses even when nobody is present to approve each step.
