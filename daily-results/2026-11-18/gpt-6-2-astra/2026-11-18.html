NOV 18, 2026

📊 AI INDUSTRY PULSE

OpenAI put GPT-6.2 Astra and Sol into Codex, ChatGPT Work and its API. Developers choosing between them now have independent test results as well as OpenAI’s launch claims: Artificial Analysis places Astra second on its Intelligence Index, while Sol approaches the previous Astra’s score at a lower cost per task.

Tencent took a different route, releasing Hy4 flash weights that teams can run themselves. Microsoft used Ignite to make the case for specialized models, including separate releases for coding, image editing and live audio.

🌐 TOP STORIES

OpenAI Releases GPT-6.2 Astra and Sol in Codex, ChatGPT Work and the API

New developments: With the GPT-6.2 release, OpenAI made both models available to Plus, Pro, Enterprise and Edu users in ChatGPT Work and Codex. The rollout also changes who can use the fastest mode: Pro 500 subscribers get Ultrafast on either model, while Pro 200 subscribers get it on Sol for the first time.

Tencent Opens Hy4 Flash Weights Under Its Own License

New developments: Tencent has released the weights for Hy4 flash, including FP8 and base variants. Teams that previously accessed the model as a service can now run it under the Tencent Hy License. The model accepts text and images, generates text and supports up to one million tokens of context.

Microsoft Introduces Seven MAI Models at Ignite

Microsoft introduced seven models spanning coding, cybersecurity, imaging, real-time audio, transcription and decision-making. For developers choosing a coding model, Microsoft says MAI Code 2 delivers 98% of GPT-6.1 Sol’s coding quality at about 40% of the price on its evaluation. That comparison is specific to Microsoft’s mix of coding tests.

Apple Releases Two FastFrames Models for Interactive Video Generation

Apple released FastFrames in two sizes: a 1.3-billion-parameter model and a 14-billion-parameter model. Both generate 480p video using two diffusion steps. Apple’s published latency breakdown for the smaller model totals 35.4 milliseconds on one GPU with a full cache, a specific test condition rather than a general latency guarantee.

Perplexity Introduces One API for Models From Multiple Providers

Perplexity’s Orchestrator API lets developers specify a model without choosing the provider that will serve each request. Perplexity says it selects the provider using availability, capacity and latency, and puts open-weight and proprietary models on one bill. Choosing the model and choosing where it runs are separate decisions.
