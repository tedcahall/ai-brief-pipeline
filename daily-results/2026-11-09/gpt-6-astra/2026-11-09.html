🌐 TOP STORIES

LG Opens K-EXAONE-2.5 API Access as Korea Expands Secure AI Agents

LG AI Research is opening API access to K-EXAONE-2.5, developed using NVIDIA Nemotron datasets, according to NVIDIA. In the same announcement, Hyundai Motor Group is exploring NemoClaw and OpenShell, while AIM Intelligence is integrating its Starfort platform with OpenShell. These are model-access and integration announcements, not evidence that the proposed enterprise deployments are already operating at scale.

Artificial Analysis Adds Calibration and Private Tasks to Decision Index

Artificial Analysis released Decision Index v2, raising the private-dataset share from 25% to 45% and rewarding calibrated confidence alongside correctness. Its new document benchmark requires all 15 answers for a document to be right. The evaluator reports higher scores for leading language models, but substantially greater cost and latency than specialized decision models; the results describe this benchmark, not universal superiority.

SemiAnalysis Reports TileRT Speed Gain for AMD MI355 on Long-Context Workloads

SemiAnalysis reports that AMD MI355 running TileRT reached 1,330 p90 tokens per second per user on long-context workloads, 1.42 times its cited GB300 NVL72 comparison. The post credits AMD with supplying an MI350 cluster to TileRT maintainers. This is an attributed workload-specific result, not a claim that AMD wins on aggregate throughput, cost efficiency, or every inference configuration.

Nous Adds Evidence-Tracked Security Reviews to Hermes Agent

Nous Research announced an official Hermes Security plugin that maps attack surfaces, divides repository review among subagents, and checks findings against code and reachable attack paths. Optional confirmation tests run reproductions in a temporary repository copy, and reports export to SARIF. The documentation distinguishes code-backed findings from test-confirmed results and warns that temporary copies are not a security sandbox.

NSE Deploys Liquid Cooling for Expanding On-Premises AI Compute

India’s National Stock Exchange has deployed direct-to-chip liquid cooling for its on-premises AI infrastructure, according to a release reported by The Economic Times. The exchange plans to exceed 80 GPUs this quarter; the cooling infrastructure is designed for up to 224. Keeping those figures distinct matters: 224 is supported expansion capacity, not the number of GPUs reported as installed today.
