# Archive notes

## Selection

Files are copied byte-for-byte from canonical local artifacts, not browser download copies. Filenames have no numbered download suffixes. Reports are not regenerated or repriced during import.

- The full-cohort corrected consensus report replaces the earlier mixed-date and today-only reviews.
- The rerun update replaces the original incomplete-cohort consensus and cost reports.
- The final scaled model summary replaces both earlier summary and corrected-unscaled variants.
- The latest token-cost report includes the route-independent pricing repair. Older daily reports retain the limitations and rates documented at the time.
- The later authorized Luna one-off HTML replaces its blocked original under the regular model directory.
- The separate Astra OpenRouter route experiment is retained under its explicitly named model/route directory; its HTML existence is not a success claim.
- Historical HTML may have `blocked`, `in_progress`, or `review_required` metadata. This is an output archive, not certification that every run passed. Stale run metadata is preserved below as recorded.
- Superseded retries, raw fetched HTML, histories, previews, JSON evidence, logs, screenshots, and ZIP bundles are excluded from daily-results. No HTML is invented for days/models without an output.
- Existing source references inside archived reports may point to the original workspace or evidence files not included here; consult the manifest. Report bodies remain unchanged.
