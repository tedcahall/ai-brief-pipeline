# Who Max Follows

[Open the directory](https://tedcahall.github.io/ai-brief-pipeline/docs/who-max-follows/).

A saved snapshot of the active source list for Max’s AI Brief. Search by name, account, company, or keyword. Sort by Original (the curated order), @name, or Company then @name. Company sorting uses the first displayed company; blank companies appear last. Sorting does not change the source ordering.

`index.html` is self-contained. `directory.json` contains the public profile snapshot in curated order. Internal editorial filters and account credentials are not included. Updates are manual snapshots; no scheduled refresh is configured.
