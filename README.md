# AI Brief Pipeline

Private archive of AI Brief model-comparison reports, token-cost reports, and daily model HTML results.

- [Model comparisons](model-comparison/): final revision of each saved analysis.
- [Token costs](token-costs/): final saved daily reports and distinct route diagnostics.
- [Daily results](daily-results/): `YYYY-MM-DD/model/` containing HTML only.
- [Archive notes](docs/archive-notes.md): selection rules and exceptions.
- [Import manifest](docs/import-manifest.json): original relative source paths and SHA-256 hashes.

This initial import does not relocate production code, modify schedules, deploy the website, or enable automatic synchronization. Originals remain unchanged. No workflows are installed.
